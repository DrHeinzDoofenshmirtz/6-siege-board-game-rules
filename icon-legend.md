# Icon Legend — Rainbow Six Siege: The Board Game Rulebook

This file maps the small graphical icons used throughout the rulebook (which
plain OCR could not read) to a consistent text/emoji notation used in
`Rules-4-vision.md` and `operators.md`. Icons were identified by visually
inspecting the page images in `rules-images\Rules\` (primarily the legend on
p. 26 "Icons used for gadgets" and the annotated Operator profile on p. 11).

This is a living document — if a new icon is found during transcription that
isn't listed here yet, add it here first, then use it consistently.

## Strength / Destruction rating tiers

The game uses the same three shapes for two related concepts:
- **Strength rating**: how tough a gadget/partition is (what it takes to destroy it).
- **Destruction rating**: how strong an Operator/gadget's Destroy action is (what it can destroy).

Both use identical icons (triangle/square/pentagon in yellow/orange/red); which
meaning applies is always clear from context (e.g. "... strength rating" vs
"... destruction rating").

| Tier | Real icon | Notation used here |
|------|-----------|---------------------|
| 1 | Yellow warning-style triangle | ⚠️1 |
| 2 | Orange square | 🟧2 |
| 3 | Red pentagon | ⬟3 *(shape shown in black; real icon is red)* |

Example usage: "Barricades can be destroyed by a gadget or an Operator with
the 🟧2 or ⬟3 destruction rating."

## Diagrams / illustrations

Where a page has a diagram, floor-plan example, or illustration that
conveys rule-relevant information visually (line-of-sight examples, overlay
placement examples, etc.), it is marked in the transcription simply as:

```
[DIAGRAM]
```

No description or page reference is added — the surrounding `--- Page N ---`
marker already identifies which page to check in the physical rulebook/images.

## Text-badge "icons" (not true graphical icons — kept as-is)

These already read fine from OCR/plain text and don't need glyph substitution:
`**ACTION**`, `**REACTION**`, and gadget keywords (`Setup`, `Overlays`,
`Line of sight`, `Throwable`, `Deployable`, `Wave`, `Vertical`, `Drone`) — all
rendered as styled text badges/headers in the original, not icons.

## Notes

- If an icon's exact real-world shape/color can't be matched to a native
  Unicode emoji, this legend uses the closest reasonable glyph and documents
  the real appearance in the "Real icon" column so it can still be cross-referenced
  against the physical rulebook.
- This legend will be extended if additional distinct icons are discovered
  while transcribing the remaining pages (e.g. Stunned marker, Entryway
  Overwatch token, etc.).
