# Interpretations

This file holds user-created rulings ("interpretations") for *6: Siege –
The Board Game* questions that the rulebook (`rules/`) doesn't clearly
resolve on its own. It also covers deliberate home-rules.

An interpretation is **never** created automatically — it is only ever
added explicitly by the user, via the `create-interpretation` skill.

Each entry has three parts:

- **Title** — a short, descriptive name for the question/situation
  (used to recognize the same question in the future).
- **Ruling** — the actual decision: what happens / what is allowed.
- **Explanation** — why the ruling was made this way (the reasoning,
  any relevant rule text it's based on or extends, etc.).

## Format

```
## <Title>

**Ruling:** <the decision>

**Explanation:** <the reasoning behind it>
```
